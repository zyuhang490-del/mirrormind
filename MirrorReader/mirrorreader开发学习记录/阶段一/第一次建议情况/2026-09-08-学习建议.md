## 三、学习阶段一：只细化眼前的任务

目标：能运行、解释基础翻页逻辑，并独立完成一个相关小练习。

### L1-01：运行与观察（当前唯一在做的任务）

**整体位置**：这是“使用并观察已有程序”，不是写新功能。

在 PowerShell 中：

```powershell
Set-Location -LiteralPath 'D:\Users\Lenovo\Desktop\Mirrormind\MirrorReader'
python main.py
```

依次尝试：

1. 输入 `s`，观察当前段落和总段落数。
2. 第一段输入 `p`，观察边界提示。
3. 输入 `n` 前进；到最后一段后再输入 `n`，观察是否越界。
4. 输入 `help`，然后 `exit`。
5. 再运行一次，观察是否从上次位置继续。

预期：当前版本尚不保存进度，重新运行会从第一段开始。这是待开发能力，不是这次需要修复的错误。

**最小产出**：把实际启动结果、一个边界现象和重启现象记录下来。不需要长篇笔记。

**完成标准**：能正常退出，并用自己的话说出“当前位置如何变化”“目前缺少什么能力”。

如果 `python` 命令不可用或出现报错：只记录完整报错和所用命令，先解决运行入口，不随意重装环境。不把猜测写成结果。

### L1-02：理解最小翻页循环（L1-01 之后）

只聚焦 `read_article()` 中的 `position`、`while`、`if/elif`、`len()` 和列表索引，不要求一次看懂整个文件。

先尝试回答：

- 为什么索引从 0 开始，显示给人的段落号却加 1？
- 为什么下一段条件是 `position < len(paragraphs) - 1`？
- 退出后，这个普通变量为什么不能自动留到下一次运行？

**产出与验收**：针对三段文字，手动写出从第一段到最后一段的 `position` 值，并解释首尾保护。说不清哪个概念，就只补那个概念。

### L1-03：独立小练习（L1-02 之后）

在本阶段 `练习/` 内另写一个小程序：使用三条字符串构成列表，支持 `n`、`p`、`exit` 和首尾保护。不读文件、不写 JSON、不使用 AI API，不改 `main.py`。

**产出与验收**：自己的练习文件和实际运行结果；能解释条件，并在增加第四条字符串后仍正确运行。参考代码或接受提示是允许的，但如实记录帮助程度。

### 学习阶段一出口

能运行项目、解释核心循环、完成上述小练习，即可进入下一段基础学习；不要求所有 Python 语法都学完。若开始时已具备这些能力，可直接用证据验收后跳过，不机械重复。
