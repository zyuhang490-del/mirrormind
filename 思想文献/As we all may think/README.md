### 两个版本的区别

真正原文比节选版多了约一倍的篇幅，包含：
- 莱布尼茨与巴贝奇的历史教训（"复杂性和不可靠性曾是同义词"）
- 干式摄影的两种技术方案
- 缩微胶片的压缩计算（大英百科全书→火柴盒，百万册图书馆→书桌一端）
- 从算盘到穿孔卡到真空管计算机的完整谱系
- 形式逻辑机器
- 百货商店自动记账系统

节选版把这些技术血肉全删了，只留下概念骨架。
