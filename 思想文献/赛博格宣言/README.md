## 与 MirrorMind 的关系

哈拉维的赛博格概念是 MirrorMind 的哲学灵感来源之一。核心连接点：

- **边界崩溃** → 人机融合的合法性
- **亲缘性，而非身份** → 自结构不是找到"本质自我"，而是与过去碎片建立新连接
- **局部视角 > 总体宣称** → 语境化响应，不做全知系统
- **"我宁愿做赛博格，而不是女神"** → 拥抱不纯粹、技术中介的存在
