## 阅读与维护约定

- OCR 稿保留原始识别结果与页码，引用前应与原文核对。
- 节译、讨论和摘要必须标明范围，不能标成全文。
- 以后新增公开阅读材料优先使用 `.md`；原件可继续保存在本地。
- `mirrormind-literature-import.ris` 是供文献管理软件导入的数据，保留 RIS 格式；它不是阅读正文。
- 此次整理不改写文献论点，不新增阅读完成记录，也不把历史讨论当作已经验证的科学结论。
