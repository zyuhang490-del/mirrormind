## 核心概念速览

```
全储存层 ──── 无结构、不丢失地保存所有"认知快照"
    │
    ▼
结构化层 ──── 当下状态作为"探针"，在全储存中寻找共振
    │
    ▼
自结构 ──── 过去不是被"检索"，而是被当下重新激活、重组、产生新意义
```
