# Terminology

[English index](README.md)

These are translation choices for MirrorMind's design vocabulary. They are not claims that all terms are established technical categories.

| Chinese | English | Meaning within this project |
| --- | --- | --- |
| 镜像智能 | MirrorMind | The proposed personal cognitive terminal and the project developing it |
| 个人认知终端 | Personal cognitive terminal | A personal computing environment organized around intention, state, history, and context |
| 向内发掘，向外连接 | Explore inward, connect outward | Develop personal potential and support creation and connection beyond the system |
| 主体性 | Agency | A person's ability to understand, choose, revise, and determine purposes |
| 意图终点 | Intention-end | The person retains authority over ends; the system supports the means |
| 全储存 / 全储存层 | Comprehensive storage / comprehensive storage layer | User-authorized retention of selected events, expressions, context, failures, and unexplained material; not an obligation to record everything |
| 认知快照 | Cognitive snapshot | A record of the context needed to resume a task, including focus, questions, interruption, and next entry point |
| 跨时间共振 | Cross-time resonance | Earlier material gaining new relevance in a later context |
| 灵接 | Inspiration connection | A proposed connection between current context and earlier fragments that might support a new idea; retrieval alone does not prove inspiration |
| 自结构 | Self-structuring | Generating revisable temporary executable structures from intention, provisional state, history, capabilities, permissions, and descriptive remainder |
| 人—环境状态表示 | Human–environment state representation | An incomplete, sourced, scoped, revisable hypothesis about a person in a particular environment |
| 描述剩余 | Descriptive remainder | What the current observation, representation, interpretation, compilation, or realization does not capture |
| 失败描述性 | Failure descriptiveness | The ability to describe where a judgment fails, what assumptions it relies on, and what information is missing |
| 状态逆识别 | Reverse state identification | Using mismatches to reconsider state hypotheses, relations, and the representation scheme itself |
| 裂缝与底噪 | Cracks and background noise | The early vocabulary for anomalies and experiences a model may fail to accommodate |
| 逆结构模型 | Inverse structure model | An early proposal to use a personal baseline model's prediction errors to locate anomalies |
| 动态概率云 | Dynamic probability cloud | A speculative account of dynamically evolving connections and creativity |
| 超验推理 | Transcendental reasoning | The manifesto's speculative term for rapid, personal-history-informed inference to a best explanation |
| 激发函数 | Activation function | The project's metaphor for creating conditions for creativity; distinct from a neural network's mathematical activation function |
| 非必要转译阻力 | Unnecessary translation effort | Work required to express an intention through rigid tool conventions; necessary confirmation and reflection remain |
| 临时程序结构 | Temporary executable structure | A task-specific arrangement of inputs, processing, state, tools, interface, and outputs |
| 可遗忘 | Forgettability | The ability to revoke permission, expire or delete records, and clear derived representations |
| 实在界 | The real | In question 2, what the current symbolic scheme cannot adequately mediate; no strict identification with a particular philosopher's definition |
